06 / HOW TO READ THIS

Evidence, not a performance.

The selective PR/devlog calendar above counts merged pull requests across the public game repository and official website repository. It does not count all commits, private backend work, unmerged branches, design sessions or code authored by a particular person. The archive series counts dated entries in the preserved Build History, not the individual tasks within them. Missing days are unknown, not idle.

Evidence snapshot: —. Future entries require a new reproducible source audit. See the review-gated Build Log for curated public updates. The new public commit calendar counts reachable default-branch commits in four named public repositories by committer UTC date, with no private repo history or author personal data; it is a distinct metric from profile contributions, PRs and devlogs. No telemetry, wallet data or private tester information is published here.
