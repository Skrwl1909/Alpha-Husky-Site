04 / HOW TO READ THIS

Evidence, not a performance.

The GitHub series counts merged pull requests across the public game repository and official website repository. It does not count all commits, private backend work, unmerged branches, design sessions or code authored by a particular person. The archive series counts dated entries in the preserved Build History, not the individual tasks within them. Missing days are unknown, not idle.
