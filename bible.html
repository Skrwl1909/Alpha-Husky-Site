01 / Read the record

Proof before
presentation.

The Project Bible is not a feature checklist and not a roadmap dressed up as one. It is a public view of the current Alpha Husky record, derived from Alpha Husky Bible v1.1 EN FINAL. Older evidence stays historical. Newer code does not become LIVE until the right evidence exists.

Backend truth firstPlayer state, rewards, ownership and progression stay server-authoritative.
Build ≠ device passSource, build and physical-runtime evidence stay separate.
Known limits stay visibleOpen gates are labelled instead of being hidden behind launch language.
Verified

Supported by an appropriate audit, verifier or runtime test.

In testing

Implemented or partly verified, with a current runtime/device gate still open.

Planned

Approved direction, not presented as implemented.

Historical

Real earlier state retained for the record, not current product truth.
