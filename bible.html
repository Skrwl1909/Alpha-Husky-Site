01 / Read the record

Proof before
presentation.

The Project Bible is not a feature checklist and not a roadmap dressed up as one. It is a public view of the current Alpha Husky record, based on Alpha Husky Bible v1.1 EN FINAL, with an evidence update through 11 October 2026. The underlying master document remains v1.1; this public page is v1.2. Older evidence stays historical. Newer code does not become LIVE until the right evidence exists.
